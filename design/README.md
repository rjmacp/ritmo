# Ritmo design files

- `midnight/` — the chosen direction (Midnight Citrus), all nine screens.
- `palettes/` — palette explorations on the final layout.
- `graphite/` — previous direction, same layout, superseded. `build.py` generates the `.dc.html` artboards; `ritmo-graphite.html` is the published canvas.
- `directions/` — the 14 exploration artboards (rounds 1–4) that led to Graphite.
- `mocks/` — first pass in the old dark/orange MVP theme, superseded.

Regenerate a canvas: `python3 build.py` (or `bash build.sh`) then seed with the design skill helper.
