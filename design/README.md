# Ritmo design files

- `graphite/` — the chosen direction, all seven screens. `build.py` generates the `.dc.html` artboards; `ritmo-graphite.html` is the published canvas.
- `directions/` — the 14 exploration artboards (rounds 1–4) that led to Graphite.
- `mocks/` — first pass in the old dark/orange MVP theme, superseded.

Regenerate a canvas: `python3 build.py` (or `bash build.sh`) then seed with the design skill helper.
